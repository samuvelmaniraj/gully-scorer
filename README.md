# Gully Scorer

Live scoring for gully and box cricket. One phone scores, everyone else watches live through a link or QR code.

- No sign-up and no database. The score goes straight from the scorer's phone to viewers' phones.
- Viewers can only watch; they cannot change the score.
- Tap "End match and delete" when you finish and the match is gone.

Hosted free with GitHub Pages. The whole app is the single file `index.html`.
