# Gully Scorer

Live scoring for gully and box cricket. One phone scores, everyone else watches live through a link or QR code.

**Start a match:** https://samuvelmaniraj.github.io/gully-scorer/

- No sign-up and no database. Scores are end-to-end encrypted and signed, so only people with the match link can read them and only the scorer can change them.
- Quick score or Full scorecard, coin toss, free hit, scorer handover, and a TV-style match summary to share on WhatsApp.
- Each match is removed from the relay 12 hours after its last update.
