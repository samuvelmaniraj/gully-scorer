    Share on WhatsApp 
    
    
    
    
    
      Share stats with your WhatsApp group
      
    
        
    
          
    Send one link to your WhatsApp group. Players tap it any time to see everyone's stats, and every finished Full scorecard match is added automatically. No accounts or logins. The stats are kept online but encrypted, so only people with the link can read them.
    
          
        
    
        
    
          
    
          
    
            
            
          
    
          
    
            Add another scorer
            
          
    
          
    Send the scorer link only to people who score. Anyone with it can add and remove matches. The players' link can only view.
    
          
        
    
        
    
      
    
    
    
    
    
      Backup and merge
      
    
        
    More than one scorer? Each scorer taps Save backup and sends the file to one phone. On that phone, tap Merge a backup and pick the file. Matches already on the phone are skipped, so nothing is counted twice.
